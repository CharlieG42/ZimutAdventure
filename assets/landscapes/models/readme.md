# Photos de référence — modèles du monde

Photos personnelles servant de modèles pour le world design de ZimutAdventure.
Toutes les photos montrent des paysages de **canyon de l'Ouest américain** (région de départ du jeu) :

| Fichier | Sujet | Utilisé pour |
|---|---|---|
| `canyon_panorama_01.heic` | Panorama falaises rouges, mesas à sommet plat, ciel dégagé | Composition générale du terrain, horizon lointain |
| `canyon_strata_01.jpg` | Parois stratifiées rouges/orange, colonnes rocheuses | Shader du terrain (strates sédimentaires), couleurs ocre/rouge |
| `canyon_hoodoos_pines_01.jpg` | Hoodoos (cheminées de fée) et pins dispersés | Props `RockGenerator` (hoodoo) + `VegetationGenerator` (pin) |
| `canyon_hoodoos_02.jpg` | Hoodoos en grès ocre, lumière rasante du soir | Proportions des hoodoos, éclairage chaud de fin de journée |
| `canyon_trail_pines_01.jpg` | Sentier de terre rouge, champignons rocheux, conifères | Sentiers, rochers champignons, palette sol rougeâtre |

> Le fichier `.heic` est au format HEIC (iPhone). Pour le visualiser sur un PC, le convertir en JPEG
> (ex. via l'app Photos de Windows, ou `heif-convert` sous Linux).
